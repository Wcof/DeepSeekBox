DeepSeekBox：DeepSeek Harness 插件中心

DeepSeekBox 是 DeepSeek Harness（DSH）桌面端的插件中心：在一个面板里浏览、安装、更新、启用或停用插件，聚合多个插件索引源，把装不上的版本提前标出来；上游只把修复合在分支上时，可以直接按分支安装。它本身也是一个可安装的 DSH 组合包，并对外发布一份可供订阅的插件索引。

MIT 许可 DSH 0.2.1-rc.5 验证 format 1 插件索引 macOS

它能做什么

插件管理与市场

读取宿主真实的 pluginManager / pluginMarket 服务，整包启停、逐行启停、安装、更新、卸载都落在当前 profile。

多索引源聚合

把已订阅的索引合并成一个列表，按来源分组、按作者筛选，并显示每个索引源的条数与错误。

兼容性提前可见

按索引登记的 engines.dsh 判断：当前 DSH 装不上的版本标「版本不符」并禁用安装，而不是装到一半回滚。

按分支安装

点卡片左下角的版本号，选仓库分支直接安装。适合上游把修复放在分支上、还没发版的场景。

安装

方式一：从插件索引安装（推荐）

  1. 打开 DeepSeek Harness 的「发现 → Index sources」，添加 https://raw.githubusercontent.com/Wcof/DeepSeekBox/main/index.json
  2. 搜索「插件中心」或 deepseek-box，点安装
  3. 重启 DSH 窗口（Host 端代码在启动时加载）

方式二：命令行

dsh plugin --profile web add github:Wcof/DeepSeekBox

桌面端把 --profile web 换成实际的 profile 名（通常是 desktop）。

插件索引源

索引遵循 DSH 的 format: 1，任何 DSH 实例都可以订阅：

地址说明
https://raw.githubusercontent.com/Wcof/DeepSeekBox/main/index.json 始终最新，推荐
https://cdn.jsdelivr.net/gh/Wcof/DeepSeekBox@main/index.json CDN 镜像，缓存约 12 小时
https://cdn.jsdelivr.net/gh/Wcof/DeepSeekBox@<commit-sha>/index.json 按提交固定，内容不变

索引里每个版本都登记了 source: { type: "git", url, commit } 与 engines.dsh；后者原样取自该提交的 package.json。

收录与来源标签

标签含义
DSH 官方DSH 官方维护或收录，索引里带 official 标记
DeepSeekBox 收录收录在本项目的索引里，属于本项目的整理，不代表官方背书
第三方来自其他订阅的索引源

常见问题

DeepSeek Harness 插件在哪里安装？

在「发现 → Index sources」添加索引地址后搜索安装，或在终端执行 dsh plugin --profile web add <包名或 git 地址>。装完需要重启窗口。

插件显示「版本不符」是什么意思？

该版本的 engines.dsh 不包含你当前的 DSH 版本。宿主安装后会按 semver 校验并拒绝回滚；DeepSeekBox 把这个判断提前到列表里。

按分支安装和普通安装有什么区别？

普通安装装固定提交；分支安装装分支当前的头提交，会随上游推送变化，适合还没发版的修复。

「DeepSeekBox 收录」是 DSH 官方收录吗？

不是。它只表示收录在本项目的索引里；官方收录另有 official 标记。

English

DeepSeekBox is a plugin center for DeepSeek Harness (DSH): install, update and enable DSH plugins, aggregate multiple plugin index sources, flag versions the running DSH cannot load, and install from a git branch when upstream has not published a release. It is itself an installable DSH bundle and publishes a format: 1 plugin index that any DSH instance can subscribe to. 

dsh plugin --profile web add github:Wcof/DeepSeekBox
