## 背景与约束

- 项目当前为空仓库（仅 `.git`，无提交），前端技术栈由本 Goal 确立：Vue 3 + Vite + TypeScript，不引入 UI 组件库，样式手写以精确还原参考图。
- 无真实后端：以前端 service 层模拟插件内核接口（内存状态 + 异步延迟），保证后续可替换为真实 IPC/HTTP 客户端。
- 全局规范适用：F3 状态诚实（loading/ready/empty/error 分离）、T7 错误结构化、红线操作（不提交 Git，用户未要求）。

## 页面与功能边界

### Tab 1 本地插件

- 顶部工具栏（右对齐）：名称/作者/插件 ID 搜索框、检查更新、一键更新 (N)、本地安装、开发指南、刷新。
- 插件卡片：图标、名称、别名 · 插件 ID（mono）、状态标签（运行中 / 已停用 / 未找到插件文件 / 可更新）、描述、版本信息、插件文件路径（mono）、代码仓库外链。
- 卡片操作：
  - 运行中：更新（有更新时）、停用、配置、删除。
  - 已停用：启用、配置、删除。
  - 未找到插件文件：前往商店下载（跳转商场 Tab）、配置、删除（状态保留在类型与组件逻辑中，当前初始数据未包含该状态）。
- 删除必须经二次确认弹窗。
- 「配置」进入该插件的独立配置页面（全页视图，含返回、基本信息、可编辑配置项、保存反馈）。

### Tab 2 插件商场

- 顶部工具栏：搜索框、类型筛选下拉（全部 / 可安装 / 已安装）、检查更新、本地安装、开发资料、刷新。
- 列表按创作者分组（分组头：中文名 + GitHub ID + 主页外链）；未收录进官方库的插件归入「其他创作者」分组。
- 插件卡片：图标、名称、别名、插件 ID、官方收录/第三方标签、描述、版本 · 许可证、商店来源、开发作者、代码仓库（mono）。
- 卡片操作按状态：
  - 未下载：下载。
  - 已下载（未运行）：启用、删除。
  - 已下载（运行中）：停用、删除。
- 删除同样二次确认。

### 全局状态要求

- 加载中（读取中…）、空列表、搜索无结果、错误 + 重试四种列表状态齐备。
- 所有操作有即时反馈：按钮 busy 态 + 右下角通知条（含「发现可更新插件 (N)」样式）。
- 插件状态与可用操作严格一致（运行中→停用，未运行→启用，未下载→仅下载），本地与商场两 Tab 同步。

## 非目标（边界外）

- 不实现真实插件内核 / 文件系统 / 网络下载逻辑，本地安装与商场下载均为模拟。
- 不实现插件市场后端、鉴权、多语言 i18n 框架。
- 不创建 Git 提交、不推送。
